# 通传 · 飞牛应用上架自查（v1.3.3 / 2026-11-26）

对照《飞牛先锋开发者应用上架申请》提交前自查 7 条，逐项核验结论：

| # | 要求 | 结论 | 证据 / 说明 |
|---|---|---|---|
| 1 | root 权限应用无法上架 | ✅ 达标 | `config/privilege` 为 `run-as: package`；实机进程用户为 `tongchuan`，非 root |
| 2 | 鉴权优先；如监听端口需自有鉴权，不可免鉴权访问 | ✅ 达标 | 信任校验默认 `closed`：陌生设备首传被拒（实测未配对发送返回 `untrusted`、文件未落盘）；管理页需密码登录，配对靠「生成二维码 / 手动批准」；仅局域网监听，未暴露公网；安装向导可选「安全/宽松」，默认安全 |
| 3 | platform=x86/arm/all，须自行验证可装可跑 | ✅ 达标 | `platform=x86`，二进制为 x86-64；已在飞牛实机安装、启动、收传验证通过 |
| 4 | 文件读写接口校验路径安全，防路径穿越 | ✅ 达标 | `tc-core/pathsafe`：`sanitize_relative` 拒绝 `..`/绝对路径/盘符/UNC/非法字符/保留设备名，`ensure_within` 二次确认不越出目标根；落盘前双重校验 |
| 5 | 付费内容需首行声明 | ✅ 不涉及 | 应用完全免费，无付费内容 |
| 6 | 版本号必须 3 段式 x.y.z | ✅ 达标 | `1.3.3` |
| 7 | 应用名不得以「飞牛」为前缀 | ✅ 达标 | 名称「通传」/ `tongchuan` |
