# 通传安卓端 UI 重构 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把通传安卓端界面从 Java + View 体系重写为 Kotlin + Jetpack Compose + Material 3（四页底部导航），业务逻辑语义不变，版本升到 `1.0.0`。

**Architecture:** 业务逻辑保留为 Java 控制器 `TcController.java`（由原 `MainActivity.java` 去掉 View 构建后改写而来），UI 状态通过一个 Kotlin 的 `UiState`（`mutableStateOf` 属性）暴露；`MainActivity.kt` 是薄 Compose 宿主，`ui/` 下按页拆分 Composable。`ScanActivity` 保留 Camera2/zxing 内核，界面 Compose 化。

**Tech Stack:** Kotlin 2.0.21、AGP 8.7.3、Jetpack Compose（BOM 2024.12.01）、Material 3、activity-compose 1.9.3、lifecycle-runtime-compose、zxing core 3.5.3。

**Spec:** [docs/2026-11-19_安卓UI重构设计.md](2026-11-19_安卓UI重构设计.md)

## Global Constraints

- 只改 `android/`、`Cargo.toml`（版本号）、`项目状态卡.md`、`dist/`；不动 Rust / 协议 / Windows / NAS / 服务与广播的行为。
- `minSdk 26 / targetSdk 35 / compileSdk 35 / JDK 17 / 只出 arm64-v8a`，release 仍用 debug 签名。
- 版本唯一来源 `Cargo.toml` 的 `workspace.package.version`，改为 `1.0.0`；**协议号保持 `0.20` 不变**。
- 依赖复用 PartZ 的 gradle 缓存（`GRADLE_RO_DEP_CACHE`），缺的用 aliyun 镜像补；`dl.google.com` 本机不通。
- 不引第三方 UI 库；颜色/字号/形状一律走 `MaterialTheme` 令牌，禁止裸写十六进制与随手 dp。
- 注释解释「为什么」；改已有代码同步更新注释。
- 只移动不删除：旧文件移入 `cache/DSH/20261119-安卓UI重构/隔离/` 并留清单。
- 每批改动先备份（`_外置/备份/tongchuan/android-ui-refactor_<YYYYMMDD-HHmm>/`），构建通过后再收下一批。
- 验证结果分层标「实测 / 推断 / 未验证」。

## Review Focus

这五处是现有代码里最容易被重构改坏的行为，逐个在对应任务里有验证步骤：

1. **发送中退到后台 / 熄屏**：发送必须走前台服务 `SendService`，界面线程不能代替它——界面退后台不能中断发送。
2. **多目标发送中途取消**：点取消后，后面排队的目标不得再开始。
3. **落点查询期间换目标**：旧目标的查询结果必须作废，不能把 A 的落点用到 B。
4. **从「所有文件访问」设置页返回**：接收目录已自动切到 `Download/局域网通传`，界面要 `recreate()` 并重启接收服务，否则显示与实际落点不一致。
5. **Android 13+ 通知权限缺失**：启动前台服务前必须先要通知权限，否则被系统直接拒绝。
