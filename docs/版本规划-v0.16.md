# v0.16 手机指定接收位置（设计稿）

> 定档 2026-11-15：原 v0.17 提为 v0.16，中断策略加固暂缓。目标是不登 NAS 也能把这次的文件放进指定存储空间。

## 1. 现状与目标

- 落点固定为接收端 `config.toml` 的 `destination`，发送方只有「发/不发」两种选择。
- 目标：发送前能**查询**对端有哪些可用落点，并在清单里**指定**本次落点。
- 安全边界不变：可用落点来自接收端配置，发送方只能选标识，不能造路径。

## 2. 配置

```toml
destination = "/vol1/1000/SSD/通传/Download"   # 默认落点，旧行为不变
allow = ["/vol1/1000/SSD/通传/Download", "/vol2/1000/好3T/通传收件"]

# v0.16：发送方可选的落点。path 必须落在 allow 内；id 唯一、非空
[[destinations]]
id = "ssd-download"
name = "SSD-下载"
path = "/vol1/1000/SSD/通传/Download"

[[destinations]]
id = "h3t-inbox"
name = "好3T-收件"
path = "/vol2/1000/好3T/通传收件"
```

- 未配置 `destinations` 时，自动派生一条：`id = "default"`、`name` 取默认落点的目录名。旧配置零改动。
- 启动校验：`destination` 与每个 `destinations[].path` 都必须在 `allow` 内；`id` 不能重复、不能为空。任一条不满足直接拒绝启动并说明是哪一项。

## 3. 协议（新增字段均可缺省，旧端忽略）

| 位置 | 新字段 | 语义 |
|---|---|---|
| `HELLO_ACK.destinations` | `[{id, name}]` | 接收端可选的落点清单（只有标识与人可读名字，不含完整路径） |
| `MANIFEST.destId` | 字符串，可选 | 本次落点标识；缺省 = 默认落点 |
| `DESTS` / `DESTS_ACK` | 查询不带参数，回 `destinations` | 发送前查询用；与正式传输共用同一次 HELLO 握手 |

- 未知标识：接收端回 `BUSY{ reason: "unknown destination: <id>（可用：a, b）" }`，在回 `MANIFEST_ACK` 之前拒绝，不落盘、不占路径。
- 旧发送端不带 `destId` → 默认落点；旧接收端不认识该键 → 忽略，发送端仍按默认发，不会断连（0.15 与 0.16 因版本门禁本来就不互通，这条是给 0.16.x 内互操作留的）。
- 查询会话：接收端回完 `DESTS_ACK` 就结束，不写历史、不占并发名额（报告里标 `query_only`，daemon 与 Android 跳过历史计数）。

## 4. 各端改动

- **内核**（`tc-core`）：`DestEntry`、配置解析与校验、`handle_session` 解析 `destId`、查询会话、`list_destinations()`。
- **CLI**：`tc dests --to IP:PORT [--peer-fp]` 打印可选落点；`tc send/resend --dest-id ID`。
- **Android**：选定目标后后台查询落点，显示「接收位置：<名称>」一行，点开单选；发送时把 `destId` 带给 JNI。查询失败不阻塞发送（退回默认落点，并提示一句）。
- **管理页**：本版不做落点选择，发送仍走默认落点（记录在案）。
- **手机接收端**：不提供多落点（SAF 权限模型不同），清单里只有派生默认项。

## 5. 验收

1. e2e：接收端配两个落点，发送端指定第二个 → 文件落在第二个目录，第一个目录无残留；回执 `destDirs` 正确。
2. 未知标识：发送端指定 `nope` → `BUSY` 且原因含可用标识；接收端不建目录、不占路径。
3. 缺省：不带 `destId` → 落默认目录，行为与 0.15 一致。
4. 查询：`list_destinations()` 返回两个落点，名称与配置一致；查询不产生历史记录。
5. 真机：手机选 NAS 的第二个存储空间发送小文件，文件实际落在该目录；选一个白名单外标识被拒且提示可读。
6. 门禁：`cargo test --workspace` 全绿、`scripts/verify.ps1` 8/8。

## 6. 不做

- 发送方传任意路径（安全边界）。
- 接收端按发送方要求动态创建落点（目录必须由接收端配置预先声明）。
- 管理页落点选择与历史里的落点切换（留待需要时再加）。
