# 通传 · 服务器端计划

## 已交付

- 无头守护进程：传输、发现、并发会话、信任门禁、管理页、剪贴板中继。
- 以 systemd 服务常驻，二进制与数据集中在一个用户目录，不需要 root 权限。
- 管理页令牌鉴权；落点受 `allow` 白名单限制。
- 升级方式为备份后原地替换二进制并重启，数据与信任关系保留。

## 后续可选方向

以下均为可选增强，不是承诺；按实际需要再排期。

- 打包成发行版软件包或应用商店包，减少手工装服务文件的步骤。
- 服务健康监控与外部告警接入。
- 管理页的多用户与权限区分（当前只有单一令牌鉴权）。
- 大目录扫描的增量哈希缓存：登记在 [功能展望-版本路线.md](./功能展望-版本路线.md) 的 2.4 候选池，默认关闭、需人工拍板风险；与 `map v3` 同批但独立提交，批次随中断加固重新排期而定。
