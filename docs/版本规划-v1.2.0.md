## 6 发送页重排 + 右上角扫码图标

- `SendScreen.kt` 由上到下固定为：**发送到 → 发送内容 → 开始发送 → 附近设备 → 接收位置 → 最近发送**。
- 右上角新增一个**扫码图标按钮**（图标形如扫描框，用户提供截图：四角框 + 中间横线）。点它 = 原「扫二维码配对」（作为发送端扫码）+ 「展示二维码」（作为接收端出码给自己扫）合并入口：弹出一个菜单/对话框，提供「扫对方的码」与「展示我的码」两项。
  - 复用现有 `ScanActivity`（扫码）与 `controller.showPairDialog()`（展示二维码 + `PairQrDialog`）。
- 图标资源：新增一个 vector drawable（扫描框），放在 `android/app/src/main/res/drawable/`。

## 7 设置页（新 SettingsScreen）

设置页自上而下：
1. **安全**（可展开区块，**默认收起、默认不启用**）
   - 一个总开关「启用安全功能」（默认关，持久化到 SharedPreferences）。
   - 开启后才显示：**发现与信任**（发现按钮 + 信任设备列表/批准/撤销 + 本机指纹）、**配对**（配对码输入 + 展示二维码按钮）。
   - 关闭时只显示总开关与一句说明「安全功能默认关闭，开启后可管理信任设备与配对」。
   - **「默认不启用」的实现定义**：仅隐藏/停用这些**管理入口与出码/发现主动操作**；底层接收信任门禁（`trust_mode=closed`）照旧生效，不因开关关闭而放开——即「关」不等于「信任放开」，只是高级操作默认收起，避免误触与界面复杂。
2. **常驻接收**（从设备页迁入）：状态 + 启停按钮 + 刷新状态。
3. **权限与保活**（从设备页迁入）：所有文件访问 / 无障碍增强 / 电池白名单。
4. **接收目录**（从设备页迁入）：当前目录 + 选择 + 恢复默认。
